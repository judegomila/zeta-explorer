# Gated modular-pair endpoint-layer search

This isolated workstream follows the completed all-degree analytic sweep. It
does not extend the old finite-degree atlas. It tests two theorem-shaped
objects extracted from that sweep:

1. the exact exponential generating function for all graded theta features;
2. the signed `h` versus `-h` endpoint layer at the two candidate scales
   `h=c/N` and `h=c/N^2`.

The old supervisor and old queue are not restarted. Nothing here writes to the
live 4CT checkout or to `experiments/rsst-layer3/scripts`.
