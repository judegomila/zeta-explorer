# Paths an automated engine may commit. Read by scripts/engine-guard.mjs.
#
#   allow <glob>   the path may be committed by an engine
#   deny  <glob>   the path may not be committed by an engine (wins over allow)
#
# Globs: "*" matches within one path segment, "**" matches across segments,
# a trailing "/" means "everything under this directory".

# deny list: changing what engines may commit is a reviewed change.

# A second, built-in list in scripts/engine-guard.mjs (HARD_DENY) applies to
# every commit, engine or not, and cannot be relaxed from here.
