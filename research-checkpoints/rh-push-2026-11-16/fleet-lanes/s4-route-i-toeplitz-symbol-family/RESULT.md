## 0. Controls and conventions

Weil form of an object F with completed function Q^s prod_j pi^(-s/2) Gamma((s + kappa_j)/2) F(s), poles of F at 1/2 +- p, on real g in L^2(-a,a), h = g * g~ (CLASSICAL):

    W_F(g) = sum_poles (abs(ghat(ip))^2 + abs(ghat(-ip))^2) + (1/2 pi) int w(t) abs(ghat(t))^2 dt - sum_n n^(-1/2) c(n) (h(log n) + h(-log n)),
    w(t) = 2 log Q + sum_j (Re psi(1/4 + kappa_j/2 + it/2) - log pi),   c = coefficients of -F'/F.

"Pole-free" = restriction to ghat(+-ip) = 0 (the form T_a[sigma_2] of the Route I nodes; in the basis used by the source, sigma_2 = (t^2 + 1/4)^2 w_1 and the Rayleigh quotient has a different normalisation, so signs agree and eigenvalues do not). "S-truncation" = c(n) kept only for n in the multiplicative monoid generated by S (for an Euler product: the prime powers of S), everything else as in the object. Adjoining P_3 to the one-prime symbol is the passage from S = {2} to S = {2,3}.

Cause, read from the source code (`tmp/imp-97183-csharp-extprec-ladder.py`, function `build`): the matrix is A_nm = (1/pi) int_0^T sigma_2 R_n R_m dt with T = 200. The basis functions (a^2 - x^2)^3 P_n(x/a) have transforms decaying like t^-4 past t = n/a, and sigma_2 grows like t^4 log t, so the integrand decays only like log t / t^4 times an amplitude that grows with n; the cut-off removes a positive part that grows with N. The source's own docstring records the T-dependence at the same N (lambda_min at ln 3, N = 52: 0.467 at T = 200 in imp-97560 against 0.577 at T = 800). The time-domain assembly used here has no cut-off. ARGUED (the source script was read, not re-run with larger T).

Consequence for the nodes: the one-prime crossing is 2a* = 1.1315(1), the margin above ln 3 is 0.033 and is N-stable; the sub-gap "imp-97560-crossing-asymptote" has the answer "strictly above ln 3" at the level of Ritz values (an upper bound for the infimum cannot exclude a lower true crossing, but no N-trend towards one exists in this assembly). The number ln 3 has no meaning for the one-prime symbol, which contains no information about the prime 3.

## 8. Three weakest steps

1. The explanation of the drift in imp-97560 (frequency cut-off T = 200) is read from the source code and from the T-dependence recorded in the source's own docstring; the source script was not re-run at larger T. What is measured here is that the exact time-domain assembly shows no drift (N = 20 .. 400).
2. All positive values in combinations 1 and 3 are Ritz upper bounds computed with midpoint balls (not interval-certified). The classifications use signs of values of size 1e-4 and larger, or negative values (negative values of the form up to the accuracy of the matrix entries, computed at 448 or 640 bits with Gauss quadrature that is exact for the polynomial parts; entry radii were not propagated), except the zeta S = {2,3}, {2,3,5}, {2,3,5,7} brackets, where the last positive value is of size 1e-12 to 1e-41 and is resolved by ball arithmetic (N-stable from N = 44 on).
3. Section 4's derivation of the conductor scaling is a degrees-of-freedom count, not a proof; the constant alpha q varies between -4.3 and -5.2 on the fit range and the larger conductors are not asymptotic there.
