# Key results: two-stage stress test, 2026-11-21

Each of the 22 items of the site's Key results page (`src/data/key-results.js`) was re-run and
attacked by a first reviewer and then by an independent referee. This folder holds the outcome.

- `RANKING.md`: the ranked table, what did not survive or was weakened, where the two reviewers
  differed, and what was not independently verified.
- `<id>/VERDICT.md`: the first reviewer's verdict for the item with that id.
- `<id>/REFEREE.md`: the referee's pass on that verdict. Where the two differ, the referee's value
  is the one used on the page.

Both reviewers were AI agents. Nothing here is an external or peer review.

Not included: the reviewers' scripts, logs and working notes. File and folder names inside the
reports (`NOTES.md`, `referee/`, `replay/`, `push/`, script names) refer to the reviewers' working
copies and are not in this repository. Statements such as "private", "working branch" and "public
clone" in the reports describe the reviewers' working copies on 2026-11-20/21.
