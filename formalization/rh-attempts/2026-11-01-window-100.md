has β = ½. Equivalently: for each c > 0, in every ordinate interval J ⊂ [T₀, ∞) of length c/log(sup J), all zeros are
simple and on the line.

**Equivalences** (PROVED; E2 uses vortex README Theorem A, which is internal and unrefereed):

## 1. Setting

- ξ(s) = ½ s(s − 1) π^{−s/2} Γ(s/2) ζ(s). For a zero ρ = β + iγ of multiplicity m_ρ put δ_ρ := β − ½ and
  γ_ρ := (ρ − ½)/i = γ − iδ_ρ. The zero is on the line iff γ_ρ is real. The functional equation pairs ρ with 1 − ρ̄, and
  γ_{1−ρ̄} = conj(γ_ρ).
- Height T, density factor l := log(T/2π), bandwidth B > 0, L := Bl, X := e^L = (T/2π)^B. AF use B = 1.
- Window φ (AF (2.7)): even, 0 ≤ φ ≤ 1, supp φ = [−L/2, L/2], φ ≡ 1 on [−L/2 + w, L/2 − w], with C^∞ ramps of length w.
  The flat window is w → 0, φ = 1_{[−L/2, L/2]}. Put a := ‖φ‖²₂/L and φ̂(z) := ∫ φ(u) e^{−iuz} du.
  - For real r: |φ̂(r)| ≤ ϑ(r) := min(L, 2/|r|, C_χ/(w r²)), and ∫ϑ² ≤ 8L.
  - For complex z: |φ̂(z)| ≪_χ e^{L|Im z|/2} ϑ(Re z) (AF (2.8)).
- Atoms: a finite set A = {α₁ < … < α_d} ⊂ ℝ, usually a lattice of spacing h = 2π/L (B atoms per mean zero spacing).
  - v_ρ := (φ̂(γ_ρ − α_k))_{k ≤ d}.
  - G_A := (aL²)^{−1} Σ_ρ m_ρ v_ρ v_ρ^T over all nontrivial zeros; the sum converges absolutely by AF (2.8).
  - G_A is real symmetric. Each pair {ρ, 1 − ρ̄} contributes 2 Re(v_ρ v_ρ^T) = 2(a a^T − b b^T), where v_ρ = a + ib.
  - AF Lemma 2.1 (Poisson–Gabor): for the full lattice, Σ_k φ̂(z − α_k) φ̂(z′ − α_k) = L·(φ²)^(z − z′). Every zero, on
    or off the line, contributes exactly 1 to the trace.
- A **window** is J = [e₁, e₂] together with an atom set A_J ⊂ J and a counted multiset Z_c of zeros. G_c is the part of
  G_{A_J} from Z_c, E := G_{A_J} − G_c, and N(Z_c) := Σ_{ρ ∈ Z_c} m_ρ.
- For a symmetric matrix M: λ₁(M) ≥ λ₂(M) ≥ …, n₊(M) := #{i : λ_i(M) > 0}, N_θ(M) := #{i : λ_i(M) > θ}.

## 2. The argument

### Step 1. The inertia criterion (no-loss form of AF §§3–4)

**Lemma 1 (PROVED; v1, re-checked).** Let G ∈ ℝ^{d×d} be symmetric with

  G = Σ_{j∈S} v_j v_j^T + Σ_{j∈M} m_j u_j u_j^T + Σ_{l∈O} μ_l · 2Re(w_l w_l^T) + E,

where v_j, u_j ∈ ℝ^d, w_l ∈ ℂ^d, the m_j ≥ 2 and μ_l ≥ 1 are integers, and ‖E‖ ≤ θ. Put
N := |S| + Σ_M m_j + 2 Σ_O μ_l. If N_θ(G) ≥ N, then M = O = ∅.

*Proof.*
1. By Weyl, λ_i(G) ≤ λ_i(G − E) + ‖E‖, so N_θ(G) ≤ n₊(G − E).
2. n₊ is subadditive: Weyl's λ_{i+j−1}(X + Y) ≤ λ_i(X) + λ_j(Y), with i = n₊(X) + 1 and j = n₊(Y) + 1.
3. n₊(Σ_S v v^T) ≤ |S| and n₊(Σ_M m u u^T) ≤ |M|.
4. Each 2Re(w w^T) = 2(a a^T − b b^T) is the pull-back of diag(2, −2) under x ↦ (a·x, b·x), so n₊ ≤ 1 (AF Lemma 3.1).
5. Hence N ≤ |S| + |M| + |O|, i.e. Σ_M (m_j − 1) + Σ_O (2μ_l − 1) ≤ 0. Every term is ≥ 1, so M = O = ∅. ∎

**Corollary 1 (window form).** If ‖E‖ ≤ θ and N_θ(G_{A_J}) ≥ N(Z_c), every zero in Z_c is simple and on the line.

**No loss.** If the zeros of Z_c are simple, on the line, have linearly independent vectors, and λ_{N(Z_c)}(G_c) > 2θ,
then N_θ(G_{A_J}) ≥ N(Z_c). So Corollary 1 loses nothing beyond the conditioning margin 2θ. AF's Lemma 3.2 bounds rank P₁
through tr G and ‖G‖²_HS; Corollary 1 reads the positive index directly. (This is Hermite/Sylvester inertia counting of
real roots, as in route 27's Toeplitz ghost index and Bombieri's count of off-line pairs in truncations of Weil's form.)

**The window statement.**

  (NL_J): N_{θ_J}(G_{A_J}) ≥ N(Z_c), with θ_J an a priori bound for ‖E‖.

By Corollary 1, (NL_J) for every window implies Theorem W.

### Step 1′. What (NL_J) contains: simplicity (new in v2)

Let 𝔉 be the class of functions F that are entire of order 1, real on ℝ, satisfy F(1 − s) = F(s) and F(1) = ξ(1), and
have all zeros in 0 < Re s < 1. The zero multiset is then invariant under ρ ↦ ρ̄ and ρ ↦ 1 − ρ. For F ∈ 𝔉 define the
window matrix by its zero side, G_A(F) := (aL²)^{−1} Σ_ρ m_ρ v_ρ v_ρ^T. For F = ξ it equals the prime-side expression of
Lemma 4.

**Definition.** A *window certificate* is a pair (𝒜, 𝓗):
- an acceptance set 𝒜 ⊂ Sym_d(ℝ) × ℕ, where (M, N) ∈ 𝒜 means "accept";
- a hypothesis 𝓗 on the uncounted zeros (for example ‖E‖ ≤ θ, or a depth bound).

It is
- *zero-side sound* if, for every F ∈ 𝔉 whose uncounted zeros satisfy 𝓗, (G_A(F), N(Z_c)) ∈ 𝒜 implies that the counted
  zeros of F are on the line;
- *open* if each slice {M : (M, N) ∈ 𝒜} is open.

Examples:
- Corollary 1 is zero-side sound, because Lemma 1 uses only the zero side. It is open, because {λ_N(M) > θ} is open.
- The two-moment integrality certificate of Proposition 2(e) (AF's chain read per window: accept if
  4 tr M − 2N − ‖M‖²_HS > N − 1, with 𝓗 an a priori trace-norm bound on E small enough for the integrality step) is
  zero-side sound and open for the same reasons.
- A positivity certificate {λ_min(M) > −θ} is open but **not** sound: Table 10 shows an RH-false configuration that
  passes it at T = 2·10^4.

**Proposition R (PROVED).** Let (𝒜, 𝓗) be zero-side sound and open. Let F ∈ 𝔉 satisfy 𝓗, and suppose Z_c contains a zero
½ + ic of F on the line of multiplicity m ≥ 2. Then (G_A(F), N(Z_c)) ∉ 𝒜.

*Proof.*
1. For 0 < η < ½ let Q₀(s) := (s − ½ − ic)²(s − ½ + ic)² and Q_η(s) := Π_{±,±}(s − ½ ± η ± ic). Put
   F_η := κ_η F Q_η/Q₀ with κ_η := Q₀(1)/Q_η(1).
2. F_η ∈ 𝔉. F/Q₀ is entire because ½ ± ic are zeros of F of multiplicity ≥ 2 (conjugate symmetry). Both Q_η and Q₀
   are invariant under s ↦ 1 − s and under conjugation, and F_η(1) = F(1).
3. Its zeros are those of F with two copies of ½ ± ic replaced by ½ ± η ± ic. The uncounted zeros are unchanged, so F_η
   satisfies 𝓗, and N(Z_c) is unchanged.
4. Z_c(F_η) contains the off-line zero ½ + η + ic, so soundness gives (G_A(F_η), N) ∉ 𝒜.
5. As η → 0, G_A(F_η) − G_A(F) = (aL²)^{−1}[2Re(w_η w_η^T) − 2 v_c v_c^T] → 0, where w_η := (φ̂(c − iη − α_k))_k → v_c
   because φ̂ is entire.
6. The complement of the open slice is closed and contains every G_A(F_η), so it contains their limit G_A(F). ∎

The difference is second order: 2Re(w_η w_η^T) − 2v_c v_c^T = −2η²(v_c′v_c′^T + sym(v_c v_c″^T)) + O(η⁴). AF §7.2(b) notes
that off-line pairs of depth → 0 are "spectrally the same" as doubles. MEASURED (Table 10):
‖G_pair(η) − G_double‖ ≈ 0.16–0.18 (ηL)² for ηL ≤ 0.5, at T = 2·10^4 (B = 2, two windows) and 6·10^5 (B = 3).

**Corollary R (PROVED).** If an open, zero-side-sound certificate accepts every window J ⊂ [T₀, ∞), with any choice of
A_J and Z_c covering J, then every zero with γ ≥ T₀ is on the line **and simple**. A proof of Theorem W by such
certificates is a proof of RH ∧ SZC on [T₀, ∞).

*Scope.*
- The same proof applies if 𝓗 also bounds the depth of the counted zeros by some δ₀ > 0: take η < δ₀.
- Proposition R does not cover a certificate whose soundness uses arithmetic beyond the window matrix (a certificate
  sound for ξ but not for all of 𝔉). Such a certificate must encode Euler-product information that G_J does not carry;
  see 6I.
- The point is not that Theorem W mentions simplicity (it does, by definition). Even if only RH is wanted, a certificate
  of this kind cannot accept a window with an on-line multiple zero. So the method cannot deliver RH without also
  delivering SZC.

**Proposition S (function fields; PROVED, with classical inputs).**
- Setup: C/F_q is a curve of genus g with Frobenius eigenvalues α₁, …, α_{2g}, and α_j/√q = e^{iθ_j} with θ_j real by
  Weil's theorem. For N ≥ 2g let T_N := [S_{j−k}]_{0≤j,k<N} with S_n := q^{−n/2} Σ_j α_j^n.
- Then T_N ⪰ 0 and rank T_N = #{distinct α_j}.
- So the function-field analogue of W100's inertia statement, "n₊(Weil Gram) = number of zeros counted with
  multiplicity", holds iff the Frobenius eigenvalues are distinct. It fails for every curve with a repeated eigenvalue,
  for example every supersingular elliptic curve over F_{p²} that is the base change of a curve over F_p with a_p = 0
  (α = β = −p), and the maximal curve y² = x³ − x over F_9.
- RH holds for all of these curves.

*Proof.* T_N = Σ_j u_j u_j^*, u_j := (e^{ikθ_j})_{k<N}. Vectors with distinct θ are linearly independent for
N ≥ #{distinct θ} (Vandermonde). Zeros of ζ_C(s) are multiple iff two α_j coincide. (Route 27 PROVED: Q_TL has rank equal
to the number of distinct Frobenius eigenvalues.) ∎

**Theorem L (PROVED).**
- Fix α ∈ ℝ satisfying (H_α): ζ has no zero with β > ½ and ordinate γ = ±α.
  - (H₀) holds unconditionally: ζ(s) < 0 on (0, 1), by the alternating series for (1 − 2^{1−s})ζ(s).
  - (H_α) holds for |α| ≤ 3.0·10^12, by Platt–Trudgian.
- If D_α(W) ≤ C(1 + W)^m e^{εW} for all real W ≥ W₀, with 0 ≤ ε < ½, then ζ(s) ≠ 0 for Re s > ½ + ε.

*Proof.*
1. For Re q > ½, termwise integration gives the transform
   M_α(q) := ∫₀^∞ D_α(W) e^{−qW} dW = (2q²)^{−1}[(−ζ′/ζ(½ + q − iα) − 1/(q − ½ − iα)) + (−ζ′/ζ(½ + q + iα) − 1/(q − ½ + iα))].
   The continuum term cancels the poles at q = ½ ± iα.
2. M_α is meromorphic with poles only at q = 0 and q = ρ − ½ ± iα (and trivial zeros, with Re q < 0). A pole on the real
   half-line q > 0 means ρ = ½ + δ ∓ iα with δ > 0, excluded by (H_α).
3. Let f := C(1 + W)^m e^{εW} − D_α on [W₀, ∞), and 0 before W₀. Then f ≥ 0, and its abscissa is ≤ ½ since
   |D_α| = O(e^{W/2}) by Chebyshev. Its transform is R − M_α + (entire), with R holomorphic for Re q > ε.
4. If σ_c(f) > ε, the right side would continue L_f holomorphically across the real point σ_c, contradicting Landau's lemma
   (atlas-arith §2). So σ_c ≤ ε, and M_α is holomorphic on Re q > ε.
5. A zero ρ with δ = β − ½ > ε gives a pole of M_α at q₁ = δ + i(γ + α) with residue −(m_ρ + m_{ρ′})/(2q₁²) ≠ 0. Here ρ′ is
   the possible zero at ½ + δ + i(γ + 2α), whose residue has the same sign. Contradiction. ∎
