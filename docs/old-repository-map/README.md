# Map from the earlier repository to this one

This repository was created on 2026-11-20 from an earlier private repository (`judegomila/mathexplorer`). The history was carried over with every commit's original author and date, but commit hashes changed, and pull-request numbers were not carried over. Files in the research record (`research-checkpoints/`, `rigorous/`, `research/`) still contain links to the earlier repository; they are left as written because those files are covered by checksum manifests and source-binding records. Use this page to resolve such a link.

## Resolving a link

- **`.../mathexplorer/pull/N`**: find `N` in the table below. The work is on the branch named there, and for most rows it is also in `main`.
- **`.../mathexplorer/blob/<hash>/<path>`**, **`/tree/<hash>/...`**, **`/commit/<hash>`**: look up `<hash>` (or its prefix) in [`commit-map.tsv`](commit-map.tsv), take the new hash, and use `https://github.com/judegomila/zeta-explorer/blob/<new hash>/<path>`. If the path still exists, `https://github.com/judegomila/zeta-explorer/blob/main/<path>` usually shows the current version.
- A hash that is not in the map belonged to a commit that touched only files that were not carried over.

`commit-map.tsv` has 10,658 rows (old hash, new hash). 491 earlier commits have no counterpart here.
