## 0. Verdict

1. The three papers are consumers/extensions of the half-plane. None contains a new input on the zeros of zeta.
   At K = Q, Cureton-Thorner gives zeta zero-free for Re s > 31/32, weaker than the 7/8 already used.
2. New for this project (PROVED given the cited half-planes, section 3): the substitution lemma of
   papers/lambda-qrh-0.116091 carries over verbatim to every L-function with a de Bruijn-Newman constant in Dobner's sense:
   - every primitive Dirichlet character chi: 0 <= Lambda_chi <= 9/32 = 0.28125 (input: openai/math 7/8);
   - every number field K and every primitive finite-order Hecke character: 0 <= Lambda_K, Lambda_{K,chi} <= 225/512 =
     0.439453125 (input: Cureton-Thorner 31/32);
   - with Liu 2610.26835 (CLAIMED, Lean "in progress") instead: <= 0.281079996... for all of these.
   The bounds are uniform over the family. The unconditional bound for these functions is 1/2.
3. The barrier chain that takes zeta from 9/32 to 0.116091 does NOT transfer today: its inputs (W) and (J) are
   zeta-specific certificates at height 6e12. Nothing comparable exists for L(s,chi) or zeta_K. The pure strip bound is

4. Uniformity over all number fields gives nothing for zeta beyond K = Q (section 5).
5. Labeling: both topology/number-theory papers state their theorems conditionally on a named hypothesis and call the
   proofs "claimed". The project wording is consistent with that practice (section 6).

## 1. Facts: Cureton-Thorner (CLAIMED; Lean-formalized; not refereed)

- Title: "Report: A quasi-Riemann hypothesis for Dedekind zeta functions". Investigators: Dean Cureton, Jesse Thorner.
  Hexagon page labels: "A mix of human-written and AI-generated text", "Human understanding: some parts".
  Provenance statement: "The proofs and Lean formalization were generated by AxiomProver."
- Theorem 1.1 (v2): for every number field K, zeta_K(s) != 0 for Re s > 31/32, s != 1. eps = 1/32.
- Corollary 1.2 (v2): for every finite-order Hecke character chi over K, L(s, chi, K) != 0 for Re s > 31/32 wherever
  holomorphic (s = 1 included for nonprincipal chi).
- Version history: the v1 PDF states 1 - 1/6000 (Theorem 1.1, Theorem 5.1, eq. (6.1): f(Z) << Z^{7/15 - 1/6000 + eps}).
  The v2 PDF states 31/32 (f(Z) << Z^{287/800 + eps}, shift 61/100, 61/100 + 287/800 = 31/32). Both versions carry the
  page date 12 Oct 2026. The v1 HTML page displays the v2 abstract (31/32); the v1 PDF is the authority for v1.
  This explains the two citations: Frei-Sofos-Widmer v2 (14 Oct) quotes QRH(1/6000); Baldwin-Sivek (4 Nov) quotes 1/32.
- Scope: all number fields, not only abelian ones. K = Q gives zeta at 31/32; cyclotomic K gives Dirichlet L at 31/32.
  Both are weaker than the openai/math 7/8 for zeta and Dirichlet L.
- Method (sections 2.1, 2.3, 5.1):
  1. Analytic core over F containing mu_12 (Theorem 5.1: zeta_F zero-free for Re s > 31/32). It follows the adelic
     argument of the OpenAI primitive-roots preprint ([30], which had 1 - 10^-6 for cyclotomic F containing mu_12):
     a smoothed reciprocal f(Z) = (1/2 pi i) int Z^{s-61/100} e^{(s-5/6)^2} H(s)/zeta_F^S(s) ds is bounded by evaluating
     one weighted average of cubic theta sums twice: Kazhdan-Patterson cubic exceptional theta representation +
     Goldmakher-Louvel quadratic large sieve for the upper bound; Tate/Poisson summation for a principal term containing
     1/zeta_F^S; Huxley large sieve + Moebius-polynomial zero detector for the other frequencies. Table 1 of v2: the
     binding saving is the theta-side upper bound, exactly 1/32; the least Poisson saving is 7949/250000.
  2. Descent to arbitrary K: F = K(zeta_12) is abelian over K of degree <= 4; abelian class field theory gives
     zeta_F = zeta_K * prod over nontrivial chi of Gal(F/K) of L(s, chi, K), all factors entire, so a zero of zeta_K is a
     zero of zeta_F. The paper states: "No assumption on the normal closure of K, and no higher-dimensional Artin
     holomorphy theorem, is used."
  3. Hecke L-functions (section 14): for chi of order r, the cyclic class field L/K of ker chi has
     zeta_L = zeta_K * prod_{j=1}^{r-1} L(s, chi^j, K); apply Theorem 1.1 to L.
  So: abelian (class-field) factorization only, used twice. No Brauer induction, no Artin holomorphy, no Aramata-Brauer.
- Lean (section 15 and repository README): Theorem 1.1 and Corollary 1.2 are formalized; Solution proves
  `DedekindZetaZeroFree.main` and `DedekindZetaZeroFree.heckeCorollary` from Challenge/DedekindZetaChallenge.lean;
  README states only `propext`, `Quot.sound`, `Classical.choice`; "the repository reports successful verification with
  the Lean comparator". Statement of `main` (read from the challenge file): for every number field K there is f,
  differentiable on C minus {1}, equal to Mathlib's `NumberField.dedekindZeta K` for Re s > 1, with f s != 0 for
  31/32 < Re s, s != 1. The Hecke statement uses the repository's own `RayClassCharacter` structure (narrow ray class
  characters on ideals). Dependencies: Mathlib, Tau Ceti, a vendored class-field-theory development, and code adapted
  from openai/math ("analytic number theory") and LeanPool. Repository created 12 Oct, last push 13 Oct 2026.
  Not built in this run; the project has no local check of this certificate.
- Independence from the 7/8 certificate: partial. Different system and repository, but the strategy is OpenAI's and
  part of the analytic code is adapted from openai/math.

## 2. Facts: Frei-Sofos-Widmer and Baldwin-Sivek

Frei-Sofos-Widmer (arXiv:2610.18491v2):
- QRH(delta): no zero with Re s > 1 - delta, delta in (0, 1/2].
- Theorem 1.1 (their own, by modifying Lagarias-Odlyzko; no AI used): if zeta_L satisfies QRH(delta), then for L/K
  Galois, every class C, every x > 2: |pi_C(x, L/K) - (#C/#G) Li(x)| <= c_1 (#C/#G) x^{1-delta} log(Delta_L^{1/delta} x^{n_L}).
  The only new lemma is the bound sum_{|rho|<1/2} 1/|rho| << log(Delta_L^{1/delta}) (Lemma 2.3), which uses |rho| >= delta.
- Corollaries: splitting primes of norm << (log Delta_L)^{1/delta} (log log Delta_L)^{2/delta}; Chebotarev in short
  intervals; Ellenberg-Venkatesh l-torsion bound #Cl_L[l] << Delta_L^{1/2 - 1/(2l(d-1)) + eps}; an averaged moment bound;
  Ruppert's small-generator bound. Each needs QRH(delta) only for the Dedekind zeta of one field (the normal closure).
- Hypothesis is per field (zeta_L), not uniform; uniformity is needed only for constants independent of the field.

Baldwin-Sivek (arXiv:2611.06705v1):
- Hypothesis 1.2: one eps > 0 with zeta_K zero-free in Re s > 1 - eps for every number field K.
- Theorem 1.3: unknot recognition, 3-sphere recognition, torus/hyperbolic knot recognition, hyperbolicity of cusped
  3-manifolds are in coNP modulo Hypothesis 1.2. Mechanism: FSW Theorem 1.1 with L = K (effective prime ideal theorem,
  Corollary 3.3) -> Theorem 2.1 (an irreducible f in Z[x] has a root mod some prime p = poly(d, log||f||)) -> Koiran /
  Kuperberg certificate. Uniformity in K is essential here (K = Q[x]/(f) varies with the input).
- "No generative AI was used at any point in the writing of this note."

## 3. Lambda for Dirichlet L-functions and Dedekind zeta functions

Setting (CLASSICAL, Dobner 2021, Theorems 1-3). For F in the extended Selberg class S# (Dirichlet series, continuation
with a pole of order m at 1, completed xi^F = gamma F with gamma(s) = alpha s^m (s-1)^m Q^s prod Gamma(omega_i s + mu_i),
Re mu_i >= 0, and the functional equation making H^F(z) = xi^F((1+iz)/2) real on the real axis), put
Phi_F = Fourier transform of H^F and H^F_t(z) = int e^{t u^2} Phi_F(u) e^{izu} du. Then there is a real Lambda_F with:
all zeros of H^F_t real iff t >= Lambda_F; and Lambda_F >= 0. S# contains zeta, every primitive Dirichlet L-function,
every Dedekind zeta function and every primitive finite-order Hecke L-function. The normalisation z -> (1+iz)/2 is the
one of the project paper and of Polymath 15 (zeta: strip |Im z| <= 1, Lambda <= 1/2). In the other common normalisation
xi(1/2 + iw) all values below are divided by 4.

Theorem A (strip bound for S#). PROVED from CLASSICAL inputs.
Let F in S# and 1/2 <= theta. If F(s) != 0 for Re s > theta, s != 1, then for every t >= 0 every zero z of H^F_t has
(Im z)^2 <= max((2 theta - 1)^2 - 2t, 0), and
    0 <= Lambda_F <= (2 theta - 1)^2 / 2.
Proof. For Re s > theta >= 1/2 the factors s^m, Q^s and Gamma(omega_i s + mu_i) of gamma have no zero; at s = 1 the
factor (s-1)^m cancels the pole of exact order m, so xi^F(1) != 0; elsewhere xi^F = gamma F != 0 by hypothesis. The
functional equation maps a zero rho to 1 - conj(rho), so all zeros of xi^F have 1 - theta <= Re s <= theta, i.e. all
zeros of H^F have |Im z| <= 2 theta - 1. Dobner's proof of his Theorem 1 verifies that Phi_F satisfies the hypotheses of
de Bruijn's Theorem 13 (his Theorem 3: phi(u) = conj(phi(-u)), phi(u) = O(exp(-|u|^b)), b > 2). That theorem with
Delta = 2 theta - 1 gives the strip at time t; at t = (2 theta - 1)^2/2 all zeros are real, so Lambda_F <= that value.
Lambda_F >= 0 is Dobner's Theorem 2. QED.
This is Lemma 4.1 (lem:subst) of the project paper with zeta replaced by F; the only extra facts are Dobner's two
theorems. For zeta it is the existing lemma.

Corollary B (numbers). Each line is conditional on the half-plane named; Theorem A itself is not.

- No relation between Lambda_K and the constants of the factors of zeta_K is proved. H^F for a product is the product,
  so the time-0 zero sets add, but the heat flow multiplies the kernel Phi_{F1} * Phi_{F2} (a convolution) by e^{t u^2},
  which is not a convolution of the flowed kernels. "Lambda_K >= Lambda_Q" and "Lambda_K <= max of the factors" are OPEN.

Verified-height input that exists:
- Dirichlet: Platt (Math. Comp. 2016, abstract): GRH for all primitive chi of modulus q <= 400000 to height
  t_0 = max(1e8/q, 7.5e7/q + 200) (q even) or max(1e8/q, 3.75e7/q + 200) (q odd). So q * t_0 >= 1e8: the analytic

- Dedekind: no systematic verification to large height. For abelian K of conductor f the zeros are those of Dirichlet
  L-functions of conductor dividing f, so Platt gives height >= 1e8/f for f <= 400000. For non-abelian K only isolated
  low-height computations exist (cited from memory, not re-read: Tollis 1997, cubic and quartic fields, heights < 100).
- For the uniform statements (all chi, all K) no finite verification can enter: infinitely many functions.

Consequence. For a single chi with q <= 400000 the bound available today is the strip bound 9/32. A chain analogue
would have its head at analytic-conductor height about 2e8 (z-coordinates) instead of 6e12.
HEURISTIC size of what such a chain could give, if (W) and (J) were ported: the paper records Raymond's chain at
theta = 7/8 with head at X, 10X, 100X, 1000X: 0.118506, 0.112236, 0.107056, 0.102616 (decrements per decade 0.0063,
0.0052, 0.0044, shrinking with height). Extrapolating 4.5 decades down gives a value between about 0.15 and 0.17.
This is an extrapolation outside the computed range, with the mean zero density log(q x/4 pi) about 0.62 of zeta's;
the error terms of the approximations grow at low height. It is not a claim. It only shows that the porting work
(one chain at analytic conductor 1e8, valid for all q <= 400000 at once) would be worth roughly 0.11-0.13 below 9/32.
For Dedekind zeta with eps = 1/32 the start is q0 = 225/256 = 0.879, close to the classical 1; a chain would recover
most of its descent from floors, but there is no verified height to build (W) on.

Side fact for the zeta chain: if only the Cureton-Thorner certificate were accepted for (H1) (theta = 31/32 at K = Q),
Theorem 4.2 of the paper applies with q0 > 225/256 and (H2), (H3) give a value between Raymond's 0.149395 (start 1) and
0.118506 (start 9/16); linear interpolation in q0 gives about 0.141 (HEURISTIC, the run was not made).

## 5. Does uniformity over all number fields give anything for zeta?

No, by four separate observations.
1. Zeros (PROVED, trivial). A zero-free half-plane for a product is the intersection of those of the factors. The
   statement "all zeta_K zero-free for Re s > theta" contains "zeta zero-free for Re s > theta" as the case K = Q and,
   for zeta, nothing else. Cureton-Thorner at K = Q is 31/32 > 7/8. The descent runs from the big field to the small one
   (a zero of zeta_K is a zero of zeta_{K(zeta_12)}); information never flows from the other factors to zeta.
2. The classical inter-factor mechanism is Deuring-Heilbronn repulsion: an exceptional real zero of one factor repels
   the zeros of the others. A uniform half-plane excludes exceptional zeros (beta <= theta < 1 for every real chi), so
   the hypothesis of that mechanism is empty. (CLASSICAL mechanism; the remark is elementary.)
3. Liu 2610.26835 (CLAIMED): B_flat = 0.874886647 for every (K, chi). Its value at K = Q is the number already recorded
   on the site from Xu-Sang; the paper's own summary: implied constants depend on the field, "the boundary is independent
   of K and chi". The sibling note ../zf-hecke-all-fields/RESULT.md shows the extremal configuration is in the sextic
   twist family, not in the target: no target, zeta included, gets a bound below the supremum over the twist family, and
   feeding GRH for the whole family into the comparison system moves the output by at most 4.32e-5. So a better uniform
   input over fields does not move the zeta abscissa in this method. The Lambda value at B_flat is the 0.116060107834762
   of ../lambda-from-halfplane/RESULT.md (gain 3.14e-5 over 7/8).
4. Lambda (section 3, last remarks): Lambda = Lambda_zeta depends on the zeros of zeta only; no inequality links it to
   Lambda_K.
What uniformity does give: arithmetic consequences where the field varies with the input (Baldwin-Sivek, effective
Chebotarev with field-independent exponent, class-group torsion, least splitting primes, no Siegel zeros with a uniform
gap). These are outputs of the half-plane, not inputs to it.

## 6. How the two papers label the quasi-RH inputs; comparison with the project wording

Frei-Sofos-Widmer, introduction (verbatim): "OpenAI claims to prove ..."; "the preprint [hex26] contributed by Cureton
and Thorner claims that QRH(1/6000) is satisfied by the Dedekind zeta functions of all number fields ... These results
are supported by formalised proofs in Lean. As we, the authors of the present note, have currently not verified the
arguments in these preprints, we prefer to state all of our results conditionally on QRH(delta) for some delta in
(0, 1/2]." Every theorem carries "Assume that zeta_L has no zeros with Re s > 1 - delta". The abstract and one sentence
of section 1.3 use the word "unconditional" ("we make unconditional the Ellenberg-Venkatesh bounds"; "thus making it
unconditional by [hex26]"), so the paper is not uniform in its own wording.

Baldwin-Sivek (verbatim): "Cureton and Thorner [hex26] have recently communicated a Lean-formalized proof of
Hypothesis 1.2 with eps = 1/32 ..."; "at the time of writing it is not clear to us that any human has understood the
proof given in [hex26], so following the lead of [FSW26] we will continue to describe these results as being conditional
on Hypothesis 1.2." Theorem 1.3 reads "modulo Hypothesis 1.2"; Table 1 caption: "a proof of which was claimed in
[hex26]". The abstract says "unconditional versions" and "first unconditional proof that 3-sphere recognition is in
coNP".

Project wording (paper main.tex abstract and status box; HomePageEditorial.jsx; LambdaQrhConditionalPage.jsx):
"Assume that zeta(s) != 0 for Re s > 7/8 ..."; "It depends on two recent results that have not been refereed: the
zero-free half-plane (openai/math result family 003, whose Lean proof was rebuilt here with standard axioms only) and
D. J. Raymond's decreasing-barrier construction"; hypotheses (H1)-(H4) named in the theorem; "The accepted
peer-reviewed bound remains Lambda <= 0.2."

Comparison.
- Same convention: the half-plane is a named hypothesis in the theorem statement; the source is described as a claim;
  the Lean certificate is reported as a fact about the certificate, not as acceptance. The project matches this.
- The project is stricter than both abstracts: it never uses "unconditional". Keep that.
- One distinction the two papers make that the project sentence compresses: "two unrefereed results" puts a
  kernel-checked statement (H1) and a non-formalized written construction (H2) in one phrase. The paper's "Status of the
  hypotheses" paragraph already separates them. On the short site strings an optional refinement is "one Lean-checked,
  not human-refereed; one written, not refereed". No change is required for accuracy.
- Baldwin-Sivek's criterion is human understanding, not refereeing. The Hexagon page itself rates the report "Human
  understanding: some parts". The project's phrase "not peer reviewed" is the weaker and verifiable statement; it stays
  correct.
- Both papers state results for a general parameter (delta, eps) so that they survive changes of the constant. The
  project paper does the same through its theta table (section 6 of the paper).

## 8. Controls (brief)

- Davenport-Heilbronn: DH is in S# and has zeros with Re s > 1, so the hypothesis of Theorem A fails for every
  theta <= 1; Theorem A with its actual zero abscissa gives a positive bound, as it must (DH has off-line zeros).
  Theorem A uses the functional equation and the heat flow only; the Euler product enters solely through the half-plane
  hypotheses, i.e. through the cited papers (cubic Gauss sums / multiplicativity of Hecke characters, class-field
  factorization of zeta_F).
- Backward heat family and sign twist: Theorem A is a statement at t >= 0 about one fixed F; it makes no claim that
  survives either control, and none is needed. No RH-type conclusion is drawn.
- Flow-blindness / MV-CAP / verified height: not applicable; the output is an upper bound on Lambda_F, above 0.2.
