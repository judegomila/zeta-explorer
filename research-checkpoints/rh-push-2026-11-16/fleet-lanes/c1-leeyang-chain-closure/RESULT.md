## 0. Verdict

**The lemma is decided: no. The closure of pair-ferromagnet laws is a proper subclass of the Lee-Yang class, in the fixed-degree chain form from degree 5 on, and in the limit sense as well.**

1. Fixed degree n, n unit spins (the chain form P = wQ + Q*, Schur-Cohn parameters of Q in [0,1], closure taken). Chain set = complete-graph set = Lee-Yang set for n = 2, 3, 4 (PROVED, explicit inverse; EXACT grid checks). For n = 5 the Lee-Yang set is strictly larger: w^5 + (5/4)w^3 + (5/4)w^2 + 1 = (w+1)(w^2 - w/2 + 1)^2 and w^5 + (5/3)w^4 + (5/3)w + 1 = (w+1)^3 (w^2 - (4/3)w + 1) are Lee-Yang polynomials with nonnegative coefficients that are not partition polynomials of any zero-field pair ferromagnet of total weight 5, on any graph, with hidden spins allowed (PROVED; EXACT certificates). Exact separators also for n = 6, 7, 8, 9.
2. Tool (Theorem B, PROVED): the coefficient vector of a pair ferromagnet is multi-affine in a_ij = e^(-2 J_ij), so every lattice ferromagnet law of degree n lies in the convex cone K_n generated by the partition products prod_i (1 + w^(k_i)), k a partition of n. This is the Fortuin-Kasteleyn representation read as a convexity statement. conv(F_n) = conv of the partition products.
3. Limit sense (any number of spins, any nonnegative weights, hidden spins, weak limits with uniform exponential moments). The GHS inequality holds on this closure (CLASSICAL + PROVED limit step) and fails for the Lee-Yang polynomial (w^2 - (44/23)w + 1)(w+1)^44, degree 46, nonnegative coefficients: third cumulant of the tilted law at w = 108/55 is positive (EXACT rational arithmetic). So "limit of pair ferromagnets" is strictly stronger than the Lee-Yang property.
4. Consequence for the lane. Outcome "proper subclass" of synthesis section 6: a pair-ferromagnet representation of Phi would be stronger than RH. The extra necessary conditions found here are GHS (limit sense) and the cone K_n (fixed degree). No leverage on zeros follows.

### 2.1 Thm 6(d), restricted to the Fourier strip. PROVED-rel classical inputs named below; zero certificates EXACT (ball arithmetic).

Setting. K is a symmetrised finite Dirichlet stage kernel: real, even, continuous, K(u) = -3 pi (sum_{n<=N} n^2) e^(-5|u|) (1 + o(1)) (parent Thm 6(a)). H_t(z) = int e^(t u^2) K(u) e^(izu) du. For t < 0 it is entire. For t = 0 it is analytic exactly in |Im z| < 5, i.e. -2 < Re s < 3 with s = (1+iz)/2, and there H_0 = (s(s-1)/8) g_N(s), g_N(s) = gamma(s) D_N(s) + gamma(1-s) D_N(1-s). For t > 0 the integral diverges.

Statement (6(d')). If H_0 has a non-real zero z_0 with |Im z_0| < 5 (an off-line zero of g_N with -2 < Re s < 3), then H_t has a non-real zero for every t <= 0. For such stages no t at which the transform is defined gives a real-rooted function. If H_0 has no non-real zero in the strip, nothing is claimed.

Proof.
(a) Convergence. For |Im z| <= 5 - d the integrand is bounded by C e^(-d|u|) for all t <= 0, so H_t -> H_0 locally uniformly on |Im z| < 5 as t -> 0-. By Hurwitz there is t_1 < 0 such that H_t has a zero in a disc around z_0 that does not meet the real axis, for all t in (t_1, 0].
(b) Lemma M. Let G be an even real entire function with only real zeros and |G(x+iy)| <= C e^(tau y^2). Then G(z) = c z^(2m) e^(-a z^2) prod_k (1 - z^2/x_k^2) with 0 <= a <= tau and sum x_k^(-2) < infinity (G is in the Laguerre-Polya class).
Proof of M. g(w) = G(sqrt w) is entire and |g(w)| <= C exp(tau (|w| - Re w)/2), so g has exponential type <= tau and indicator h_g(theta) <= tau (1 - cos theta)/2; in particular h_g(0) <= 0 and h_g(pi) <= tau. The zeros of g are w_k = x_k^2 > 0. By Lindelof's theorem (CLASSICAL) the sums sum_{w_k <= r} 1/w_k are bounded for a function of exponential type; the terms are positive, so sum 1/w_k < infinity and g(w) = c w^m e^(-a w) pi(w), pi(w) = prod (1 - w/w_k), a real. A genus-zero product has minimal type (CLASSICAL), so h_pi <= 0; the inequality h(theta) + h(theta + pi) >= 0 for functions of exponential type (CLASSICAL) gives h_pi = 0 identically. Hence h_g(theta) = -a cos theta, and h_g(0) <= 0, h_g(pi) <= tau give 0 <= a <= tau.
(c) Monotonicity on t < 0. Suppose H_(t0) has only real zeros for some t0 < 0. |H_(t0)(x+iy)| <= C int e^(-|t0| u^2 + |y||u|) du <= C' e^(y^2/(4|t0|)), so Lemma M applies with tau = 1/(4|t0|). For 0 < lambda < |t0|, Fubini (the double integral of |K| e^(t0 u^2) e^(sqrt(2 lambda)|u||x|) e^(-x^2/2) converges because lambda < |t0|) gives H_(t0+lambda)(z) = E[H_(t0)(z + i sqrt(2 lambda) X)], X standard normal, which is e^(-lambda D^2) H_(t0). The operator e^(-lambda D^2) maps a Laguerre-Polya function with Gaussian exponent a to a Laguerre-Polya function when 4 a lambda < 1 (CLASSICAL: Polya; de Bruijn 1950; recalled, not opened); here 4 a lambda <= lambda/|t0| < 1. So H_t has only real zeros for all t in (t0, 0).
(d) Combine: a real-rooted t0 < 0 contradicts (a) at t in (max(t0, t_1), 0). QED.

### 2.2 Prop 7(b), restricted to the Lee-Yang class. PROVED-rel de Bruijn monotonicity and Rodgers-Tao.

Statement. Let T rho = C e^((beta/2) x^2) (rho * rho)(kappa x), beta > 0, and let Psi = C (rho * rho)(kappa .) satisfy Psi(x) = O(exp(-|x|^b)), b > 2. If rho is in the Lee-Yang class (even, transform with only real zeros), then Lambda(T rho) <= -beta/2. Consequently: (i) every fixed point of T that lies in the Lee-Yang class has Lambda <= -beta/2; (ii) Phi is not T rho for any rho in the Lee-Yang class; (iii) if RH holds, Phi is not a fixed point of T. Without RH, (iii) is not proved, and fixed points outside the Lee-Yang class are not covered.

Proof. The transform of rho * rho is the square of the transform of rho; dilation preserves real zeros; so the transform of Psi has only real zeros. H_t[T rho] = H_(t + beta/2)[Psi]. By de Bruijn (Theorem 13, b > 2) H_s[Psi] has only real zeros for s >= 0, so H_t[T rho] has only real zeros for t >= -beta/2. (i) is the case T rho = rho. (ii): Lambda(Phi) >= 0 (Rodgers-Tao). (iii): under RH Phi is in the class, so (i) applies and contradicts Lambda(Phi) >= 0. QED.

## 3. The fixed-degree question

### 3.1 The three sets

Normalisation: n unit spins, a_ij = e^(-2 J_ij) in [0,1] (a = 1: no coupling; a = 0: rigid). P(w) = sum over configurations of prod_{i<j, sigma_i != sigma_j} a_ij w^(number of up spins). P is monic, self-reciprocal, of degree n, with coefficients c_1, ..., c_[n/2].

- LY_n: monic self-reciprocal real polynomials of degree n with nonnegative coefficients and all roots on |w| = 1.
- F_n: image of [0,1]^(n(n-1)/2) (complete graph, hence any graph). Compact.
- C_n: image of [0,1]^(n-1) under the open chain. By the Szego recursion Phi_k = w Phi_(k-1) + a_k Phi*_(k-1), Phi_0 = 1, one has P = wQ + Q* with Q = Phi_(n-1), and the Schur-Cohn parameters of Q are the a_k (EXACT check against brute-force sums for n = 2..7, 120 random rational parameter vectors; `exact_small.log`).

C_n is contained in F_n, and F_n in LY_n (Lee-Yang circle theorem, CLASSICAL). A lattice law of sum lambda_i sigma_i of a finite ferromagnet with total weight n has integer cluster weights (flipping one cluster moves S by twice its weight), so F_n is the set of all such laws without hidden spins.

### 3.2 Lemma 1 (n = 2, 3, 4): all three sets are equal. PROVED.

n = 2. P = w^2 + c w + 1. LY_2 = {0 <= c <= 2}. Two spins: c = 2a. Equal.

n = 3. P = w^3 + c w^2 + c w + 1 = (w+1)(w^2 + (c-1)w + 1). LY_3 = {0 <= c <= 3}. Chain: c = a_1 + a_2 + a_1 a_2. Inverse: a_1 = c/3, a_2 = 2c/(3+c), both in [0,1] for 0 <= c <= 3. Equal.

n = 4. P = w^4 + c_1 w^3 + c_2 w^2 + c_1 w + 1 = w^2 (x^2 + c_1 x + c_2 - 2), x = w + 1/w. Roots on the circle iff both roots in x lie in [-2,2]:
LY_4 = {0 <= c_1 <= 4, c_2 >= 0, c_2 >= 2 c_1 - 2, c_2 <= 2 + c_1^2/4}.
Chain (a, b, c) = (a_12, a_23, a_34): c_1 = (a + c)(1 + b), c_2 = 2(b + ac(1 + b)).
Inverse. If c_2 <= 2: b = c_2/2, a = 2 c_1/(2 + c_2), c = 0; a <= 1 is c_2 >= 2 c_1 - 2. If c_2 >= 2: b = 1 and a, c are the roots of x^2 - (c_1/2) x + (c_2 - 2)/4; they are real because c_1^2/4 >= c_2 - 2, and lie in [0,1] because c_1/2 <= 2, (c_2 - 2)/4 >= 0 and 1 - c_1/2 + (c_2 - 2)/4 = (2 - 2 c_1 + c_2)/4 >= 0. So C_4 = F_4 = LY_4.

EXACT checks (`exact_small.py`, Fractions): n = 3: 289 Schur-Cohn vectors on the grid (k/16)^2 all land in LY_3, and 193 grid points of LY_3 have the stated preimage. n = 4: 2197 Schur-Cohn vectors on (k/12)^3 and 4096 complete-graph parameter vectors on {0,1/3,2/3,1}^6 all land in LY_4; 1169 grid points of LY_4 (step 1/16) all have the stated preimage (352 of them through the quadratic branch, verified by the root-location inequalities).

This agrees with the parent measurement "for N = 4 all 40 are reproduced by a chain".

### 3.3 Theorem B (Fortuin-Kasteleyn cone). PROVED.

Let V be a finite set of spins with weights lambda_i >= 0 (lambda_i = 0: hidden spin), couplings a_e in [0,1] on the edges of any graph, zero field. Then
G_a(w) := sum_sigma prod_{e cut by sigma} a_e w^(S(sigma)) = sum_{B subset E} [prod_{e in B} (1 - a_e) prod_{e not in B} a_e] prod_{C component of (V,B)} (w^(Lambda_C) + w^(-Lambda_C)),
Lambda_C = sum_{i in C} lambda_i.

Proof. For fixed sigma the weight is a product of distinct a_e, so G_a is affine in each a_e separately. A function affine in each coordinate of a cube is the stated convex combination of its values at the vertices. At the vertex "a_e = 0 on B, 1 elsewhere" the weight of sigma is 1 if sigma is constant on the components of (V,B) and 0 otherwise. QED. (This is the Edwards-Sokal / Fortuin-Kasteleyn representation with p_e = 1 - a_e.)

Corollaries.
(i) If the law is carried by the lattice {-n, -n+2, ..., n} and sum lambda_i = n, every Lambda_C occurring with positive weight is a nonnegative integer, so P lies in the cone K_n generated by g_k(w) = prod_i (1 + w^(k_i)), k a partition of n. Hidden spins change only the positive coefficients.
(ii) conv(F_n) = conv{g_k : k partition of n}. A linear inequality in the coefficients holds on F_n iff it holds at the p(n) partition products.
(iii) Without the constraint sum Lambda_C = n the statement is empty: every symmetric law is a mixture of two-point laws. In the limit sense (section 4) total weight is not conserved, since weight can be spread over many small spins, and K_n gives no constraint there.

EXACT check of multi-affinity at n = 5: 200 second differences, all zero (`exact_small.log`).

### 3.4 n = 5: F_5 is a proper subset of LY_5. PROVED; EXACT.

P = w^5 + c_1 w^4 + c_2 w^3 + c_2 w^2 + c_1 w + 1 = (w+1)(w^4 + d_1 w^3 + d_2 w^2 + d_1 w + 1), d_1 = c_1 - 1, d_2 = c_2 - c_1 + 1.
LY_5 = {0 <= c_1 <= 5, c_2 >= 0, c_2 >= 3 c_1 - 5, c_2 <= 1 + (c_1 + 1)^2/4}.

Partition products in the (c_1, c_2) plane (all 1024 vertices of the cube enumerated exactly): (5): (0,0); (4,1): (1,0); (3,2): (0,1); (3,1,1): (2,1); (2,2,1): (1,2); (2,1,1,1): (3,4); (1^5): (5,10).
conv(F_5) = {c_1 >= 0, c_2 >= 0, c_2 >= c_1 - 1, c_2 >= 3 c_1 - 5, 5 c_2 <= 5 + 9 c_1}.

Separator 1: 5 c_2 - 9 c_1 - 5 <= 0 on F_5 (maximum over the 1024 vertices is 0). P_0 = w^5 + (5/4) w^3 + (5/4) w^2 + 1 = (w+1)(w^2 - w/2 + 1)^2 has roots on the circle, nonnegative coefficients, and 5 c_2 - 9 c_1 - 5 = 5/4 > 0. So P_0 is in LY_5 and not in F_5, and not in K_5: it is not the law of any zero-field pair ferromagnet of total weight 5, with or without hidden spins. As a law: atoms at +-5 with mass 1 and at +-1 with mass 5/4.

Separator 2: c_2 >= c_1 - 1 on F_5 (vertex check). P_1 = w^5 + (5/3) w^4 + (5/3) w + 1 = (w+1)^3 (w^2 - (4/3) w + 1) is in LY_5 and has c_2 - c_1 + 1 = -2/3 < 0.

Direct reading of separator 1 at c_1 = 0: every spin is rigidly tied to another, the clusters are (5) or (3,2), and the two-cluster law has c_2 = (cross coupling) <= 1; LY_5 allows c_2 <= 5/4.

MEASURED description of F_5 (not proved): F_5 = LY_5 intersected with {c_2 >= c_1 - 1} and {c_2 <= 1 + c_1 when c_1 <= 1}. Evidence: 4e5 structured random samples and 400 constrained SLSQP starts give sup(c_2 - c_1 - 1) on {c_1 <= 1} equal to 2e-16; for c_1 >= 1 the Lee-Yang upper boundary is attained by (w+1)(w^2 + beta w + 1)^2. The bound c_2 <= 1 + c_1 on {c_1 <= 1} is not a consequence of Theorem B (the set is not convex there). The exact chain grid (9^4 points) attains the same extreme values at c_1 = 0, 1/2, 1, 2, 3, 4, 5, so C_5 = F_5 is consistent with the data; not proved.

### 3.6 Answer to the chain-form question

"A Lee-Yang polynomial is a ferromagnetic chain iff P = wQ + Q* with all Schur-Cohn parameters of Q in [0,1)" is an identity of sets (parent section 7 item 3), and the set it describes is all of LY_n for n <= 4 and a proper subset for n = 5 (and for n = 6..9 by the cone). The membership condition is non-trivial from degree 5.

## 4. The limit sense

### 4.1 Theorem C (GHS separates). PROVED-rel GHS; certificate EXACT.

Let L be the set of laws of S = sum lambda_i sigma_i, lambda_i >= 0, over all finite zero-field pair ferromagnets (hidden spins allowed), and cl(L) its closure under weak convergence with uniformly bounded exponential moments E e^(c|S|) for every c.

(a) For mu in L, d^3/dh^3 log E_mu e^(hS) <= 0 for h >= 0. This is the Griffiths-Hurst-Sherman inequality (CLASSICAL) applied with fields h lambda_i >= 0.
(b) The inequality passes to cl(L): M_N(h) = E e^(h S_N) are entire, uniformly bounded on compact sets by the moment hypothesis, and converge on the real axis; by Vitali they converge locally uniformly with all derivatives; M > 0 on the real axis.
(c) The Lee-Yang polynomial Q_44(w) = (w^2 - (44/23) w + 1)(w + 1)^44 has roots on the unit circle (discriminant of the quadratic is negative) and nonnegative coefficients (EXACT; the minimum coefficient is 0: binom(44,k) + binom(44,k-2) >= (44/23) binom(44,k-1) with equality at the centre). Under the tilted law p_k proportional to [w^k]Q_44 * (108/55)^k the third cumulant of k is a positive rational number (EXACT, Fractions; float value 0.0379). With w = e^(2h) this is (1/8) d^3/dh^3 log E e^(hS) > 0 at h = (1/2) log(108/55) > 0. The member m = 100, c = 50/51 gives 5.525 at w = 46/29 (EXACT sign). So Q_44 is a Lee-Yang law that is not in cl(L).
(d) Continuous model. rho(x) = x^2 e^(-x^2/2) is a positive even density with E e^(hx) = sqrt(2 pi)(1 + h^2) e^(h^2/2); the transform (1 - t^2) e^(-t^2/2) has only the real zeros +-1; (log M)''' = 4h(h^2 - 3)/(1 + h^2)^3 > 0 for h > sqrt 3. Q_m with c = m/(m+2) is its lattice version: the positivity constraint cos(theta) <= m/(m+2) is the lattice form of sigma >= 1 in (1 - 1/sigma^2 + x^2/sigma^4) e^(-x^2/(2 sigma^2)).

Scan (MEASURED, `ghs_lattice.log`): in the family Q_m, c = m/(m+2), the maximum of the third cumulant over h > 0 is negative for m <= 43 and positive from m = 44. Degree-5 grid over LY_5 and random Lee-Yang polynomials of degree <= 8: no violation (`ghs_screen.log`). This explains the parent result (no violation among 203,194 samples of degree <= 16). Whether a GHS violation exists in LY_n for some n < 46 was not determined.

### 4.2 What is not decided in the limit sense. OPEN.

P_0 (atoms +-5 mass 1, +-1 mass 5/4) is outside F_5 and K_5, and satisfies GHS (MEASURED: maximum of the third cumulant on the scan is negative; coupled pairs and triples of copies with ferromagnetic coupling also show no violation, `ghs_screen.log`). ## 7. The four requirements

- R1 (all primes together, multiplicativity essential): true at stage level only. Evidence: parent Thm 3 (referee-confirmed) uses the tensor product over prime sites with unimodular activities; the DH stage, a sum of two such products, has 55 of 55 zeros off the line while the single-character summand has 55 of 55 on it (this lane, MEASURED; parent and referee counts for other prime sets). The repaired statements of section 2 do not change Thm 3. Qualification: ordinary integers are not used; Beurling energies pass the same theorem.
- R2 (uniform in height, every window): false. The stage theorem is uniform in height, but it is a statement about the stage, which models zeta in at most one window t near 2 pi M (parent Thm 5). Nothing height-uniform about zeta is obtained.
- R3 (every control fails for a structural reason): false. DH, backward heat and an antiferromagnetic edge fail at every stage tested. E_a and T-NR fail only when their strip exceeds the heat contraction (a^2 > 1/(2 log M) for E_a, measured failure somewhat beyond) and pass at small stages. U, sign twists and Beurling systems pass every stage. The new separating conditions (GHS, K_n) do not separate DH or backward heat.
- R4 (reach the critical line from finite stages): false. Not attempted; see below.

What a limit theorem would need (stated, not supplied):
1. A sequence of pair-ferromagnet stages whose normalised transforms converge locally uniformly on an open set meeting the strip. By Hurwitz this is equivalent to the zero-free statement for the limit; for the stages of parent Thm 3 it fails on (1/2, 1] (divergence) and convergence is known only for Re s >= 1 + delta.
2. An input that fails for U. U passes every stage with the same couplings and converges on Re s > 1 to a function with a zero in the strip (parent Thm 4), so the argument must use arg chi(p) = 0, i.e. the ordinary integers or the functional equation of the limit. No such step is known.
3. Sites other than the Euler sites: on the Euler sites the free model is the only pair model reproducing Phi (parent Prop. 2), and the stage conductor matches the archimedean factor only at t = 2 pi M (parent Thm 5).
4. By this lane: the target "Phi is in cl(L)" is strictly stronger than RH. It implies GHS for Phi (true, recalled), all GHS inequalities for ferromagnetically coupled copies of Phi, and at fixed degree the cone conditions. A proof would have to establish these as well; a refutation of any one of them for Phi would close the lane without touching RH. None of them is known to fail.
