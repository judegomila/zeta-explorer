## Lemma T (norm distance): holds

(a) Local unit vectors xi_p = sum_k lambda(p)^k e_(p^k): norm^2 = 1/(1 - abs(lambda)^2), overlap 1/(1 - conj(lambda) lambda'), so F_p is as stated. A mu*-eigenstate restricted to T_S has omega(mu_n mu_m*) = conj(lambda(n)) lambda(m) (nu(1) = 1), the values of the vector state of sum over S-smooth n of lambda(n) e_n (mu_m* eta = lambda(m) eta for completely multiplicative lambda). T_S is generated by doubly commuting isometries (mu_p* mu_q = mu_q mu_p* for p != q), acts irreducibly on l^2(N_S) and contains the compact operators; the norm distance of two vector states of an irreducibly acting C*-algebra is 2 sqrt(1 - abs(overlap)^2) (Kaplansky density; CLASSICAL, recalled). Restriction does not increase the norm. Holds.

(b) F_p^-2 = (1 - 2x cos + x^2)/(1 - x)^2 = 1 + 2x(1 - cos)/(1 - x)^2, x = p^-beta. The bound log F_p <= -(1/5) x (1 - cos): with w = 2x(1 - cos) in [0, 4], log(1 + y) >= log(1 + w) >= (log 5/4) w, so log F_p <= -0.402 x (1 - cos). Checked on a grid of 99 x 40 points (maximum of log F_p + x(1 - cos)/5 is 0, at cos = 1). For beta <= 1: sum_p p^-beta (1 - cos(tau log p)) >= sum_p p^-(1+eps)(1 - cos(tau log p)) = log zeta(1 + eps) - log abs(zeta(1 + eps + i tau)) + O(1), which tends to infinity because abs(zeta(1 + eps + i tau)) stays bounded (only boundedness above is used; non-vanishing on the 1-line is not). So the product is 0 and the distance is 2. For beta > 1 the product is the Euler product, abs(zeta(beta + i tau))/zeta(beta); equality in the distance formula uses irreducibility of A on l^2(N): an operator commuting with all e(r) is diagonal (the characters k -> e(rk) separate the points of N) and commuting with all mu_n makes the diagonal constant. Holds.
Numeric: log of the partial product over p < 2e5 at beta = 1.5, tau = 1 is -0.73401; log(abs(zeta(1.5 + i))/zeta(1.5)) = -0.73421.

The statement "exactly 2 for beta <= 1" holds for every pair of mu*-eigenstates with these eigencharacters, whatever the measures nu, because the restricted values do not depend on nu. It is Kakutani's dichotomy for product vectors (CLASSICAL in type).
